# Tool catalogue

Generated by `python scripts/tools_catalogue.py --write` - do not edit by hand.

**144 tools** in **10 packs**. Only `core` is loaded at the start of a run; the agent widens its own surface with `use_tools(pack)`. See [ARCHITECTURE.md](ARCHITECTURE.md#packs) for why.

`!` marks a tool that changes device state or reaches the outside world. Those are gated by the permission policy (`--mode ask` prompts, `--mode readonly` blocks).

| Pack | Tools | Loaded by default | What it is for |
|---|---|---|---|
| `core` | 31 | yes | Loaded by default. Enough to orient on any screen and find more tools. |
| `files` | 8 | no | Read, write, search and move files across both filesystems. |
| `instagram` | 11 | no | Instagram profiles, grids, reels and comment threads. |
| `instagram_capture` | 7 | no | Segmented screen recording of reels via MediaProjection. |
| `instagram_web` | 7 | no | Instagram over HTTP, no device - far faster where it works. |
| `learn` | 10 | no | Teach the agent a new app: explore a screen, diff it, save selectors. |
| `phone` | 29 | no | The phone as a phone: radios, sensors, camera, telephony, TTS. |
| `shell` | 4 | no | Arbitrary commands at both privilege levels, plus Python evaluation. |
| `system` | 14 | no | Device state: battery, network, storage, notifications, waiting. |
| `x` | 23 | no | X/Twitter timelines, search, and the feed-shaping controls. |
